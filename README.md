# All Aboard the Expectation Station

## Visit the website

**[Open All Aboard the Expectation Station](https://falcon-expectation-station.endearingbuffalo5.chatgpt.site)**

Public and available to students, families, and staff. No sign-in required.

A buildless, responsive elementary PBIS website. Serve `dist/` with any static host. For a local preview: `python3 -m http.server 4173 --directory dist`.

Students select one of 11 pictured destinations on a vintage railway departure board. A short train transition leads to the destination’s six exact PDF expectations. Read-aloud uses the browser speech API; availability and voices depend on the device. Reduced-motion preferences are respected, and a visible motion toggle is available.

`dist/data.json` contains the exact area names and expectation statements extracted from the supplied FALCON Student PBIS Matrix. The original PDF is included for reference. The site title and navigation are additional interface copy, not replacements for matrix wording.

Artwork: generated using the built-in image generation tool. Prompt: a consistent storybook Falcon student in a 4 by 3 illustration sheet, showing listening in class, hallway walking, handwashing, turn taking, lunch manners, auditorium applause, gentle library reading, art, fair PE play, cooperative STEAM building, careful computer use, and a Falcon railway conductor. Warm navy, teal and gold gouache, no text. Asset: `dist/assets/falcons.png`.
